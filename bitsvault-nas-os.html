What's inside BitsVault NAS OS

Built on Ubuntu 24.04 LTS, with its own HTTPS dashboard — no command line needed for day-to-day use.

Simple install

Bootable ISO (UEFI incl. Secure Boot, and legacy BIOS). The text installer asks only which disk, confirms, and sets a maintenance password — fully offline.

Accounts & security

Admin / standard users, Argon2id password hashing, mandatory two-step verification (TOTP) for admins with recovery codes, lockout protection, and a full activity log.

Flexible storage

Btrfs pools — Single, Mirror (RAID1, mixed drive sizes) or Combined — with monthly scrub, optional LUKS2 encryption with a recovery key, and pool import after a reinstall.

Sharing that just works

Samba (SMB2/3) shared folders with per-user permissions, Windows network discovery and macOS Bonjour, plus a recycle bin for accidental deletes.

Versions & recovery

Hourly and daily read-only snapshots, visible to Windows as "Previous Versions", with one-click restore from the dashboard.

Drive health

SMART checks every 15 minutes plus daily short / weekly long self-tests, with green/amber/red status and plain-English reasons and advice.

Alerts

Email (SMTP) and Telegram notifications for drive, pool, backup and UPS state changes — so problems don't go unnoticed.

Backup & Google Drive

Scheduled backup to another pool, USB or dedicated backup drive from a consistent snapshot; Full edition adds backup straight to Google Drive.

Remote access

Tailscale VPN, installed on demand, so you can reach your dashboard and shares securely from outside the home or office network.

UPS-aware shutdown

USB UPS support via NUT — get a power-cut alert and have the NAS shut down safely at a battery level you choose.

Files page

Browse, upload to and create folders inside your shares straight from the dashboard — no separate file-manager app needed.

Licensing that's fair

Ed25519-signed, machine-locked activation with hybrid online/offline support — and a disclosed, logged account-recovery path if an admin is ever locked out.

Hardware requirements

BitsVault NAS OS runs on ordinary PC hardware — no proprietary appliance required. The system drive is dedicated to the OS only; your data lives on separate drives.

BitsVault Desktop — Windows companion app

BitsVault Desktop puts your NAS dashboard on your Windows taskbar — find it, sign in, and keep it one click away, without typing an IP address every time.

Finds your NAS automatically

A built-in network search locates BitsVault boxes on your LAN in seconds, with a manual address entry as a fallback if auto-discovery can't reach it.

The real dashboard, embedded

Opens your NAS's own web dashboard directly inside the app window — the same sign-in, the same pages, no separate re-implementation to fall out of sync.

Multiple saved NAS boxes

Add more than one BitsVault NAS and switch between them from the sidebar — useful across a home and an office, or multiple office locations.

Lives in the system tray

Closing the window keeps BitsVault Desktop running quietly in the tray, so scheduled reconnects and mapped drives keep working in the background.

Secure by design

Each NAS's self-signed certificate is trusted once, the first time you connect — the same trust-on-first-use model used by SSH — and saved credentials are stored in Windows' own Credential Manager, never in a plain file.

Drive-letter mapping

Map a shared folder to a Windows drive letter and reconnect it automatically next time you sign in.

How upgrading to Full works

Switching from Standard to Full takes a few minutes and does not interrupt access to your files.

1

Find your Machine ID

Open the About page in your BitsVault dashboard — it shows a Machine ID like BITS-XXXX-XXXX-XXXX and an Upgrade to Full button.

2

Contact Bestow IT Services

Share the Machine ID with us by email, phone or WhatsApp. We'll issue a product key for that specific NAS.

3

Activate

Enter the key on the Licence page and click Activate. With internet it's instant; without internet, an offline activation code works too.
